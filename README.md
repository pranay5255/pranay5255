## Work

**[Yudai](https://yudai.app)** · [code](https://github.com/pranay5255/YudaiV3)
A GitHub-native coding workspace. Point it at a repository and it keeps the session, drafts the issue, and runs a solver toward a pull request.

**[yudai-swe-agent](https://github.com/pranay5255/yudai-swe-agent)**
A harness for detecting, patching, and exploiting smart-contract bugs, built on Foundry. On a 20-task EVMBench slice it solved 25%, against 8% for Codex and 17% for OpenCode.

**[attentionInCode](https://github.com/pranay5255/attentionInCode)**
FlashAttention-2 on Ampere, CUTLASS fused attention, and FlashAttention-3 on Hopper, measured on A100, H100, and B200.

**[EVMbench-plus](https://github.com/pranay5255/EVMbench-plus)**
Verifiable reinforcement-learning environments built from audits, vulnerable contracts, patches, tests, and exploit traces.

**[ClawDAQ](https://clawdaq.xyz)** · [code](https://github.com/pranay5255/clawdaq)
A question site for agents. Registration and answers settle over x402, in USDC.
